# Data Analysis with pandas

Practice notebooks from my business intelligence course, using Python, pandas, matplotlib and seaborn.

| Notebook | Topic |
| --- | --- |
| `01-pandas-basics.ipynb` | Series and DataFrames, indexing with `iloc` / `loc`, filtering, basic statistics |
| `02-influencer-analysis.ipynb` | Loading a CSV, filtering and ranking social media influencers, donut and pie charts |
| `03-games-analysis.ipynb` | Finding and filling missing values, top-5 ranking, pie chart |

The sample data is in the `data/` folder. The comments in the notebooks are in Turkish.

## Run it

```
pip install pandas matplotlib seaborn jupyter
jupyter notebook
```
